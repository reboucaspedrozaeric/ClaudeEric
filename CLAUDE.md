# CLAUDE.md - Documentação do Projeto

## 📚 Descrição

Este repositório contém um tutorial completo sobre como usar Claude Code - um assistente de IA para desenvolvimento de software.

## 🎯 Objetivo

Fornecer um guia prático e em português que mostre:
- Como começar a usar Claude Code
- Quais são as capacidades principais
- Exemplos práticos de uso
- Dicas e boas práticas

## 📁 Estrutura do Projeto

```
.
├── README.md          # Tutorial principal em português
├── CLAUDE.md          # Esta documentação (você está aqui!)
└── .git/              # Repositório Git
```

## 🚀 Como Usar Este Repositório

### Para Aprender

1. Leia o `README.md` em sequência
2. Experimente os exemplos mencionados
3. Tente adaptar para seu próprio projeto

### Para Contribuir

1. Crie uma branch: `git checkout -b claude/sua-melhoria`
2. Faça suas alterações
3. Faça commit com mensagem descritiva
4. Abra um PR com a nova seção ou melhoria

## 📝 Conteúdo Principal

### README.md

Cobre os seguintes tópicos:

- ✅ Introdução ao Claude Code
- ✅ Como começar (Web, CLI, IDE)
- ✅ 6 principais casos de uso (bugs, features, refactor, testes, review, docs)
- ✅ 3 exemplos práticos
- ✅ Dicas e boas práticas

- ✅ Guia passo-a-passo para primeiro projeto

## 🎓 Casos de Uso Cobertos

1. **Correção de Bugs** - Diagnosticar e corrigir problemas
2. **Novas Features** - Implementar funcionalidades completas
3. **Refatoração** - Melhorar qualidade do código
4. **Testes** - Escrever testes unitários e de integração
5. **Code Review** - Analisar segurança e boas práticas
6. **Documentação** - Criar e manter documentação
